# Cari'Bond

**Bienvenue à l'agence Cari'Bond !**
Il s'agit du site vitrine de notre liste pour les campagnes BDE 2025 à l'INSA Hauts-de-France. 
Membres de la liste, programme, défis, application, film et musique : vous y retouverez tout, et même Cari'boot le chatbot pour vous accompagner sur une folle énigme.

## Prérequis
- PHP >= 7.4 (de préférence)
- Clé d'API Mistral (env. var. `MISTRAL_API_KEY) pour le chatbot

## Installation
1. Cloner le dépôt :  
   `git clone <URL> caribond_web`  
2. Placer le dossier dans votre racine web.  
3. Vérifier que `.htaccess` est pris en charge et que `Options -Indexes` est autorisé.  
4. Définir la variable d’environnement `MISTRAL_API_KEY`.
